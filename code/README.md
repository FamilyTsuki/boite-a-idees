# Maquette — Campus Life (Boîte à Idées)

Maquette interactive développée en HTML5 et CSS3 (sans framework JS externe).

## Pages incluses

- `index.html` : Fil d'actualité et liste des propositions
- `create.html` : Formulaire de création d'une nouvelle idée
- `detail.html` : Vue détaillée d'une idée, arguments et votes
- `login.html` : Page de connexion
- `settings.html` : Paramètres du compte et bascule thème clair / sombre
- `admin.html` : Espace de modération et gestion des statuts
- `admin-register.html` : Inscription staff / admin

## Lancement

Ouvrir directement `index.html` dans un navigateur ou lancer un serveur local :

```bash
python3 -m http.server 8080
```
Puis se rendre sur `http://localhost:8080`.
